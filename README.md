# CASA-MARQUES
Um sistema de cardapio, atendimento online e entrega de produtos para uma fabrica de salgados.

- Homepage:
\ Site institucional, focado em apresentar o serviço e produto.
- Cardápio:
\ Usuario podera escolher quantidade de salgados e bebidas, e colocando seu telefone para possiveis promoções.
- Pedidos:
\ Feitos e enviados para o painel da TV
- Dashboard:
\ Resumo geral de gastos e ganhos.
- CRUD de Produtos:
\ Adicionar/Remover/Editar produtos.
- Painel TV:
\ Exibira comandas com quantidade, salgados e bebidas.
- Bot Whatsapp:
\ Enviara link do carpadio digital e alerta cliente dos processos da fabrica (Em andamento, a caminho, concluido)
